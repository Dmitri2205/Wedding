# Инструкция по деплою и обновлению свадебного сайта-визитки

## Структура проекта
Все файлы сайта лежат в папке `html`. Изменения, внесенные в эти файлы, сразу отобразятся на сайте без необходимости пересборки.
Проект реализован на классическом стеке (HTML/CSS/JS).

## Деплой на VPS

Поскольку вы попросили убрать Docker, деплой будет заключаться в простом копировании статических файлов на Nginx, установленный на сервере (если не используется Docker-версия Nginx). Либо, если у вас уже есть какой-либо веб-сервер, достаточно поместить в его публичную директорию (обычно `/var/www/html/` или подобную) содержимое папки `html`.

1. Скопируйте папку `html` на ваш VPS-сервер (например, через `scp` или SFTP клиент типа FileZilla).
   ```bash
   scp -r e:/Software/DEV/Wedding/html/* root@your-vps-ip:/var/www/html/wedding/
   ```
   *Замените `/var/www/html/wedding/` на директорию, настроенную в вашем веб-сервере для этого сайта.*

## Обновление контента (Текст, Изображения, Координаты)

Для обновления информации на сайте вам нужно просто изменить нужные файлы. 
* **Главная страница:** Файл `index.html` (изменение имён, информации о расписании, дресс-коде и т.д).
* **Координаты карт:** Файл `js/main.js` (найдите строчки `const TARGET_LAT = "55.7558";` и замените на свои).
* **Фон:** Изображение лежит по пути `assets/forest-bg.png`. Просто замените картинку на новую с таким же именем (или перепишите путь в CSS).
* **Таймер:** Файл `js/main.js` (настройка точной даты вашей свадьбы).

## Редактирование прямо на сервере (через SSH)
Вы можете редактировать файлы сайта прямо с командной строки сервера:
```bash
nano /var/www/html/wedding/index.html
```
